# Bursa Demo

Tregto aksione në një bursë të simuluar — bli lirë, shit shtrenjtë, me para virtuale.

## ✨ Veçoritë

- 🏢 6 aksione fiktive shqiptare (Tirana Bank, Albanian Telecom, Adriatik Energy, Dajti Foods, Iliria Tech, Shkodra Brew) me çmime në Lekë
- ⚡ Çmimet lëvizin live çdo 2 sekonda (random walk ±2%)
- 📈 Grafik vije në canvas me 50 pikat e fundit + mbushje gradient
- 💰 Bli/Shit me validim (cash i mjaftueshëm / aksione të mjaftueshme)
- 💼 Portofol: Cash 100,000 L virtual, tabela holdings (sasi, çmim mesatar, vlerë, P/L me ngjyra)
- 🧾 Historik transaksionesh + ruajtje lokale (localStorage)
- 🧪 Treg i simuluar — para virtuale; nuk është këshillë financiare
